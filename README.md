# Funniest Time Machine Warning — entry

A program/v1 entry for the make.fun "Funniest Time Machine
Warning" bounty. `main.py` writes one warning label to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The label:

> WARNING: Returning five minutes early voids the warranty, the alibi, and in two jurisdictions, the marriage.

matter. See `CANDIDATES.md` for the full draft list this
